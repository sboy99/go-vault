# go-vault design system

Clean-room visual language inspired by dense, minimal product UIs (not a copy of any proprietary system).

## Goals

- Dark, dense, keyboard-first
- Borders over shadows
- One primary accent (default indigo `#5E6AD2`)
- 4px spacing rhythm
- CSS variables in `src/styles/tokens.css` are the source of truth
