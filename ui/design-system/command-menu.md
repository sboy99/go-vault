# Command menu

Component: `src/components/layout/command-menu.tsx`

## Behavior

- Open: `⌘K` / `Ctrl+K`
- Close: `Esc` or select
- Navigate: `↑` / `↓`, confirm `Enter`
- Filters Overview, Backups, Jobs, Settings by label/keywords

## Visual

- Centered panel, top ~15vh
- Search row with icon + input
- Dense result list, active row `bg-elevated`
- Footer hint with kbd chips
