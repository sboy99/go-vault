# Data grid

Used for Backups and Jobs lists.

## Rules

- Full-width table, no card chrome required around the grid
- Sticky header optional; keep header subtle (`text-muted`)
- Row click navigates to detail when applicable
- Dense padding (`px-2 py-1`)
- Primary-colored links for IDs / names that navigate
- Empty state centered with short copy + primary action

See also [tables.md](./tables.md) and [status-indicators.md](./status-indicators.md).
