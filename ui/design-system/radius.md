# Radius

Base token: `--ui-radius: 0.125rem` (2px).

Derived:

| Class | Formula | Approx |
|---|---|---|
| `rounded-sm` | `× 0.5` | 1px |
| `rounded-md` | `× 1.5` | 3px |
| `rounded-lg` | `× 2` | 4px |
| `rounded-xl` | `× 3` | 6px |

Prefer `rounded-md` for controls, cards, and menus. Avoid large pill radii except for status dots.
