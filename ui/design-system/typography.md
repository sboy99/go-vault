# Typography

## Family

```
Inter, ui-sans-serif, system-ui, sans-serif
```

Loaded in `index.html`. Token: `--font-sans`.

## Sizes (app defaults)

| Token | Size | Use |
|---|---|---|
| xs / 11px | `text-[11px]` | Badges, kbd, meta |
| sm / 12px | `text-[12px]` / `text-sm` | Table cells, captions |
| base / 13px | `text-[13px]` / body | Default UI |
| lg / 14px | `text-lg` | Rare emphasis |
| xl+ | sparingly | Page titles if needed |

Body default: **13px / 1.4** (`src/styles/index.css`).

## Weight

| Weight | Use |
|---|---|
| 400 | Body |
| 500 | Labels, table headers |
| 600 | Headings, button labels |
| 700 | Strong emphasis only |

## Line height

| Context | Value |
|---|---|
| Body | 1.4 |
| Compact | 1.35 |
| Heading | 1.2 |
